# How to Install Git

Before using Git and GitHub, you need to install Git on your computer.

Git is the tool that helps developers:

* track code changes
* manage project history
* collaborate with teams

Installing Git is the first practical step in learning version control.

---

# Step 1 — Visit Official Git Website

Open the official Git website:

[Git Official Website](https://git-scm.com?utm_source=chatgpt.com)

Never download Git from random websites.

Always use the official source.

---

# Step 2 — Download Git

On the website:

* click the download button
* choose your operating system

Example:

* Windows
* macOS
* Linux

The correct version is usually suggested automatically.

---

# Step 3 — Install Git

After downloading:

* open the installer
* follow the setup instructions
* keep default settings if you are a beginner

For most beginners:

> default settings work perfectly fine.

---

# Step 4 — Verify Installation

After installation, open:

* Terminal
* Command Prompt
* PowerShell

Run this command:

```bash id="1f0c78"
git --version
```

If Git is installed correctly, you will see something like:

```txt id="p6v3sa"
git version 2.xx.x
```

This means Git is successfully installed.

---

# What is Terminal?

Terminal is a place where developers run commands.

Different operating systems use different terminals:

| Operating System | Terminal Name               |
| ---------------- | --------------------------- |
| Windows          | Command Prompt / PowerShell |
| macOS            | Terminal                    |
| Linux            | Terminal                    |

You will use terminal frequently while working with Git.

---

# First Git Command

Try this command:

```bash id="a1c9d0"
git --help
```

This shows available Git commands and help information.

---

# Common Beginner Problems

## Problem 1 — “git is not recognized”

This usually means:

* Git is not installed properly
* terminal needs restart

Solution:

* restart terminal
* reinstall Git if needed

---

## Problem 2 — Installation Feels Confusing

Don’t worry.

Almost every beginner feels confused during setup initially.

Take it slowly and follow one step at a time.

---

# Why Git Installation is Important

Without Git:

* repositories cannot be managed
* commits cannot be created
* projects cannot be pushed to GitHub

Git is the foundation of modern development workflows.

---

# Beginner Tip

Do not memorize commands immediately.

First:

* understand purpose
* practice slowly
* become comfortable with terminal

Learning Git is easier through practice.

---

# Simple Summary

Installing Git allows you to:

* track code changes
* manage repositories
* work with GitHub
* start learning version control

Git is one of the most important tools for developers.
