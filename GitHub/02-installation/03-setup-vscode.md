# How to Install VS Code

VS Code (Visual Studio Code) is one of the most popular code editors used by developers worldwide.

It is:

* beginner-friendly
* lightweight
* powerful
* widely used in the industry

You will use VS Code to:

* write code
* manage projects
* run Git commands
* work with GitHub

---

# What is VS Code?

VS Code is a code editor developed by Microsoft.

It helps developers:

* write code efficiently
* organize projects
* install useful extensions
* improve productivity

---

# Step 1 — Visit Official Website

Open the official VS Code website:

[Visual Studio Code Official Website](https://code.visualstudio.com?utm_source=chatgpt.com)

Always download software from official websites only.

---

# Step 2 — Download VS Code

Choose your operating system:

* Windows
* macOS
* Linux

Click the download button.

---

# Step 3 — Install VS Code

After downloading:

* open the installer
* follow setup instructions
* keep default settings if you are a beginner

Recommended:
✅ Add VS Code to PATH
✅ Create desktop icon

# Step 4 — Open VS Code

After installation:

* launch VS Code
* explore the interface

You will see:

* sidebar
* explorer
* terminal
* editor area

Do not worry if everything looks confusing initially.

# Why Developers Love VS Code

VS Code is popular because it:

* supports many programming languages
* has GitHub integration

# Important VS Code Features

| Feature        | Purpose              |
| -------------- | -------------------- |
| Explorer       | Manage project files |
| Terminal       | Run commands         |
| Extensions     | Add extra features   |
| Source Control | Git integration      |
| Editor         | Write and edit code  |

---

# Open Terminal in VS Code

VS Code has a built-in terminal.

Open terminal using:

```txt id="g4n2pk"
Terminal → New Terminal
```

Shortcut:

```txt id="z6t8rm"
Ctrl + `
```

This terminal is very useful for Git commands.

---

# Recommended Beginner Extensions

After installation, install these extensions:

| Extension    | Purpose            |
| ------------ | ------------------ |
| GitHub Theme | Better appearance  |
| Prettier     | Code formatting    |
| Live Server  | Run web projects   |
| GitLens      | Better Git support |

You can install extensions from:

```txt id="k8p1vn"
Extensions Sidebar
```

---

# VS Code + GitHub

VS Code works very well with Git and GitHub.

You can:

* commit changes
* push code
* pull updates
* manage repositories

directly from VS Code.

---

# Beginner Tip

Do not install too many extensions initially.

Start simple:

* learn basics first
* add tools slowly

Too many extensions can confuse beginners.

---

# Common Beginner Fear

Many beginners think:

```txt id="x2v7mp"
“VS Code looks too advanced.”
```

But don’t worry.

You only need a few basic features initially.

You will become comfortable with it through practice.
