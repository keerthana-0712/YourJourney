# Git & GitHub Installation Guide

Welcome to the **Installation Section**.

In this section, you will set up everything required to start using Git and GitHub on your computer.

By the end of this section, you will:

* install Git
* create a GitHub account
* set up VS Code
* connect Git with GitHub
* prepare your system for development

This is the first practical step in your GitHub journey.

# What You Will Learn

In this section, you will learn:

* How to install Git

* How to install VS Code

# Why Installation Matters

Before using Git and GitHub, developers need a proper setup.

Without setup:

* Git commands will not work
* projects cannot be tracked
* code cannot be pushed to GitHub

A proper environment makes development smoother and easier.
