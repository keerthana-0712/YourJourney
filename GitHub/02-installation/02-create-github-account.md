# How to Create a GitHub Account

Before using GitHub, you need to create your own GitHub account.

Your GitHub account is like your:

* developer identity
* coding portfolio
* open-source profile

Many companies and recruiters check GitHub profiles during placements and internships.

---

# Step 1 — Visit GitHub Website

Open the official GitHub website:

[GitHub Official Website](https://github.com?utm_source=chatgpt.com)

---

# Step 2 — Click “Sign Up”

On the homepage:

* click **Sign Up**
* start creating your account

---

# Step 3 — Choose Username Carefully

Your username becomes part of your developer identity.

Example:

```txt id="u7v2pk"
github.com/your-username
```

Choose a username that:

* looks professional
* is easy to remember
* is simple to type

---

# Good Username Examples

```txt id="0v9mzt"
keerthanasalla
keerthana-dev
salla-codes
```

---

# Avoid Usernames Like

```txt id="g2q7kc"
coolboy123
gamerqueen999
randomname456
```

Professional usernames create a better impression.

---

# Step 4 — Add Email and Password

Enter:

* your email address
* a strong password

Important:

* use a valid email
* remember your password safely

---

# Step 5 — Verify Your Account

GitHub may ask you to:

* verify email
* solve a small puzzle
* confirm account creation

Complete the verification process.

---

# Step 6 — Customize Your Profile

After creating your account:

* add profile picture
* add bio
* add location (optional)
* add portfolio links later

Your profile helps people know more about you.

---

# Why GitHub Profile Matters

Your GitHub profile can show:

* projects
* coding consistency
* open-source contributions
* documentation skills
* learning journey

A good profile can help during:

* placements
* internships
* freelance opportunities

---

# Beginner Tip

Do not worry if your profile looks empty initially.

Every developer starts with:

* 0 repositories
* 0 contributions
* 0 followers

Consistency matters more than starting perfectly.

---

# Important GitHub Features You Will Use

After creating your account, you will later learn:

* repositories
* commits
* branches
* pull requests
* issues
* forks

These are core GitHub concepts.

---

# Real-World Understanding

Think of GitHub profile like:

> a public portfolio for developers.

Instead of showing only certificates,
GitHub shows:

* real projects
* real code
* real contributions

---

# Security Tip

Never share:

* passwords
* personal access tokens
* secret API keys

Keep your GitHub account secure.

---

# Simple Summary

Creating a GitHub account helps you:

* store projects online
* collaborate with developers
* contribute to open source
* build your portfolio

Your GitHub journey starts here.
