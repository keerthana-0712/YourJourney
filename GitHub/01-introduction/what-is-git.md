# What is Git?

Git is a **version control system** used by developers to track changes in their code and projects.

In simple words:

> Git is like a save-history system for your code.

It helps developers:

* save project history
* track changes
* manage different versions
* work safely without losing code
* collaborate with teams

---

# Why Was Git Created?

Before Git, developers had problems like:

* losing old code
* overwriting files
* confusion between versions
* difficulty working in teams

Example:

```txt id="j0g6x8"
project-final
project-final-v2
project-final-real
project-final-last
```

This becomes messy very quickly.

Git solves this problem professionally.

---

# Real-World Example

Imagine you are writing notes for an exam.

Every time you make changes, Git creates a proper history of your work.

So if something goes wrong:

* you can go back
* recover old versions
* compare changes

This is exactly how Git works for developers.

---

# What Can Git Do?

Git helps developers:

* track code changes
* restore old versions
* work on new features safely
* collaborate with teams
* manage large projects
* avoid losing important work

---

# How Git Works

Git tracks changes step by step.

Basic workflow:

```txt id="91b6uk"
Write Code
   ↓
Save Changes
   ↓
Git Tracks Changes
   ↓
History Gets Stored
```

---

# Important Git Terms

| Term       | Meaning                       |
| ---------- | ----------------------------- |
| Repository | Project folder tracked by Git |
| Commit     | Saved version of changes      |
| Branch     | Separate workspace/version    |
| Push       | Upload changes                |
| Pull       | Download latest changes       |

Don’t worry if these words look confusing now.
You will learn each one step by step.
