# What is GitHub?

GitHub is an online platform where developers store, manage, and share their projects using Git.

In simple words:

> GitHub is like Google Drive for code and development projects.

Developers use GitHub to:

* upload projects
* save code online
* collaborate with teams
* contribute to open source
* showcase their skills

---

# Is GitHub the Same as Git?

No.

Many beginners think Git and GitHub are the same, but they are different.

## Git

Git is a tool that tracks changes in your code.

## GitHub

GitHub is a platform that stores Git projects online.

Simple understanding:

```txt id="8w7eoq"
Git = Tool
GitHub = Platform
```
