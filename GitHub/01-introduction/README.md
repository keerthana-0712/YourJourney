# Simple Understanding

## Git

Git is a tool that tracks changes in your code.

Think of Git like a:

> “Save history system for your project.”

It remembers:

* what changed
* who changed it
* when it changed

---

## GitHub

GitHub is an online platform where developers store and manage their Git projects.

Think of GitHub like:

> “Google Drive for code and collaboration.”

Developers use GitHub to:

* upload projects
* collaborate with teams
* contribute to open source
* showcase their work

---

# Real-World Example

Imagine you are writing an assignment.

Without Git:

```txt
final.docx
final-final.docx
final-real-final.docx
```

This becomes messy.

Git solves this problem professionally by tracking every version properly.
