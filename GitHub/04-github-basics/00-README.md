# Important GitHub Features

| Feature      | Purpose                       |
| ------------ | ----------------------------- |
| Repository   | Stores project files          |
| Fork         | Copy another repository       |
| Pull Request | Request to merge changes      |
| Issues       | Track bugs/tasks              |
| Stars        | Bookmark/support repositories |
| Actions      | Automation workflows          |

You will learn each feature step by step.

# GitHub Workflow Overview

Basic GitHub workflow:

```txt id="m8q4vp"
Create Repository
        ↓
Clone Repository
        ↓
Make Changes
        ↓
Commit Changes
        ↓
Push to GitHub
        ↓
Create Pull Request
```

This workflow is used in real projects and companies.
